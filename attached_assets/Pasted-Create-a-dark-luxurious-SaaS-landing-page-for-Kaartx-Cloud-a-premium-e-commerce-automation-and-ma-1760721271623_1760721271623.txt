Follow the visual and brand cues of seller.kaartx.com:
- Full dark theme (black or deep charcoal) with white/off-white text.
- Accent color: Kaartx pink (#FF385C) for buttons and highlights.
- Clean modern sans-serif font (Inter or Poppins).
- Minimal, premium, Apple-style layout with generous spacing and smooth fade animations.
- Buttons: rounded, medium weight, hover glow, soft scale-up.
- Code stack: Next.js 14 (App Router) + TypeScript + TailwindCSS + Framer Motion + shadcn/ui + lucide-react.
- All text and brand name must always be spelled “Kaartx”.
